# 高中、中职与首份工作入口系统

## 1. 覆盖范围

本模块接收青少年阶段的全部结局，并把人物推进到两类可交接状态之一：进入普通高等教育，或开始一份已有完整事实的工作/家庭经济活动。1978～1982年出生人物最早在1992年进入，最迟在2006年达到24岁上限。

入口包括普通高中、中等职业教育、家庭经济活动、直接求职、短期技能训练和继续自学。青少年模块只记录了准备，本模块才会创建真实经济活动。

## 2. 普通高中和中职

学校逐年记录：学制、年级、教学日、症状与缺勤、家庭劳动缺勤、教育现金支出、学习或实训小时、内部学习进展、继续就读、离校、留级和毕业。

内部学习进展不是统考成绩；学校名称、地点、当地收费标准、招生线、分科成绩和具体中职专业在没有数据时保持为空。中职学校类型以1999、2006年普通中专、职业高中、技工学校和成人中专招生构成为锚插值，技能方向仍是明确标注的游戏假设。

普通高中毕业后，用同年“普通高校招生数/普通高中毕业生数”作为全国参考，再结合学习进展、备考小时和家庭支出生成个体结果。它不是直接照搬的个人录取概率，也不用于伪造学校或专业。

## 3. 具体工作机会

求职时先生成三项可见候选，每项都有：

- 三次产业、行业和职业。
- 单位性质与就业形式。
- 每周工时和本年可工作月数。
- 年化收入、本年实际现金收入和使用的参照口径。
- 劳动合同概率、技能匹配和录用概率。
- 因缺少地点而保持为空的单位名称。

玩家选定一项后才进行录用结算。失败会留下具体尝试和未录用事实，下一年继续生成新机会；成功后才创建 `job`。决定记录不仅保存未选候选编号，也保存未选候选当时的完整快照，之后可以在人生复盘中展示“没有走的路”。

候选目录在 `data/entry_job_catalog.json`。三次产业就业结构只调整候选权重，不直接分配个人职业。城镇单位职工平均工资不覆盖乡镇企业、私营企业和个体劳动者，因此岗位收入只按显式倍数估算，并逐项保存统计口径是否匹配。

## 4. 家庭经济活动

家庭种养、摊点或小店记录为 `family_economic_activity`，不是用人单位劳动关系：

- 单位性质为 `family_operation`。
- 合同为 `not_applicable_family_operation`。
- 工资保持为空。
- 现金结果写为玩家对家庭经营净收入的个人贡献。

家庭原有成员收入和玩家个人收入分列，最后再相加。所有共同居住成员年度收入贡献之和必须等于家庭总收入，从而避免玩家开始挣钱后被重复计入。

## 5. 历史校准

观测数据包括1992～2006年城乡居民人均收入和恩格尔系数、城镇单位职工平均工资、普通高中毕业生升入普通高校比例、1999和2006年高中阶段及中职招生结构、1991～2006年若干年度三次产业就业结构、城镇登记失业率，以及劳动法、职业教育法、国企下岗再就业、高校扩招、加入世贸组织和2005年就业再就业政策节点。

城镇登记失业率只作为时代资料保存，不把它当青年失业率。教育个体概率、短训小时、候选机会、合同、工时、收入倍数和录用概率均列在校准文件的 `assumptions` 中。

## 6. 阶段结局

- `entered_regular_higher_education`：获得下一年进入普通高等教育的结果；成年模块继续生成层次、专业方向、年度课程、兼职和毕业事实，具体学校名称保持未知。
- `entered_first_job`：受雇岗位已创建，含行业、职业、单位性质、合同、工时和收入。
- `entered_family_economic_activity`：实际家庭经济活动已创建，但没有劳动关系或工资。
- `no_job_or_higher_education_by_age_24`：到24岁仍没有形成上述结果，保留全部学习和求职尝试。

## 7. 运行与验证

```powershell
npm run youth:sample
npm run youth:batch
npm run youth:check
```

指定出生年份和随机种子：

```powershell
node scripts/simulate-youth-entry.mjs --count 1 --year 1982 --seed my-life
```

验证覆盖同种子回放、静态与动态等待选择、完整未选候选、家庭总账、教育支出、高中/中职出勤和毕业、普通高校入口、短训与自学桥接、16岁劳动边界、家庭活动非劳动关系、岗位字段完整性、来源与假设编号，以及批量路径和行业覆盖。

## 8. 当前边界

- 尚未生成省县、具体学校、专业、单位名称和本地工资。
- 父母的完整职业转移仍不在青年阶段内重建；进入成年模块后，父母会按出生年继续变老并进入照护和生存事实。
- 本模块在首份工作开始时结束；已实现的成年模块继续结算留任、晋升、失业、换岗、合同、收入和退休。
- 普通高等教育在本模块生成入口，已实现的成年模块继续处理学校生活、兼职、毕业和求职；因缺少地点资料，具体院校名称仍保持未知。
