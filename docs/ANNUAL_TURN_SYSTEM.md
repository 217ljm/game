# 逐岁回合与年度行动系统

> 本文只记录已废弃的“一年一次主要行动”协议，不描述当前可玩交互。当前版本已经支持季度多活动计划；0 岁自动记录经历，1～2 岁仅作本人反应，不再让玩家替照护者选择家庭安排。现行设计、存档与验收见 [季度人生回合系统](QUARTERLY_TURN_SYSTEM.md)。

## 为什么要改

底层模拟从一开始就按自然年生成收入、健康、学校、工作和家庭事实，但旧交互只在少数关键事件暂停。玩家完成一个选择后可能直接看到几年后的年龄，无法参与中间年份。

正式版本把“年度事实计算”和“玩家看见并完成这一岁”统一起来：从 0 岁开始，每个自然年产生一次年度行动；同一年龄如果还有升学、求职、关系或住房关键事件，会在年度行动之后继续处理。所有当年事项完成后，先展示一次年度结算，玩家确认后才进入下一岁。

## 当前协议

年度行动配置位于 `data/annual_life_operations.json`，选择与应用逻辑位于 `src/simulation/annual-operation-system.mjs`。

每个年度行动包含：

- 适用人生阶段、年龄和状态条件；
- 具体行动名称与说明；
- 每周时间投入与本年龄段可支配时间约束；
- 需要现金的行动按同年同城乡收入参考换算名义金额，并与当年可用于该行动的现金比较；
- 对当前生活安排和累计事实的修改；
- 能追溯到该行动事实的五项属性反馈；
- 自动批量模拟权重；
- 当年没有选择的其他行动。

当前版本每年有 1 个“主要行动方向”，因此年度行动彼此互斥。它表示可支配时间的重心，不表示角色全年只做这一件事。超过本年龄段时间预算或当前现金上限的行动会显示为不可执行；实际支出写入当年事实，成年后还会进入家庭年度总支出。后续仍可在这个协议上增加多个行动点和组合效果。

现金上限不是固定的“贫富等级”：未成年阶段根据当年家庭实际收入和是否出现食品需要缺口计算；青年阶段结合家庭收入相对同年同城乡参考值；成年阶段使用已有流动储蓄、上一年实际现金结余和无担保债务。界面显示当前可用于需现金行动的具体人民币额度。完整交互回归还要求实际人生中至少出现一次被约束的候选，防止这一机制退化成永远不会触发的装饰字段。

## 年龄推进规则

- 第一次交互固定为 0 岁年度行动。
- 完成某岁的年度行动与关键事件前，不得出现下一岁内容。
- 完成当年所有事项后必须停在该岁的“年度结算”，确认后年龄严格增加 1。
- 年度行动的年龄序列必须严格为 `0, 1, 2, ...`，直到死亡年龄。
- 6 岁同时存在童年结束记录和小学开始记录，但年度行动只执行一次。
- 关键事件可以与年度行动发生在同一年龄，因此界面可能连续显示两个同龄选择；这不属于重复长大。

## 存档与回放

存档版本升级到 v2。关键事件仍按人生阶段保存在 `choices`，逐岁行动按 `annual:<calendarYear>` 保存在 `annualChoices`，已经确认的年度结算按 `review:<calendarYear>` 保存在 `yearReviews`。模拟每次从随机种子和三类选择重新回放，因此逐年事实仍可确定性复现。

旧 v1 存档会自动迁移为 v2，保留原关键选择，并从 0 岁开始补做尚未存在的年度行动。

## 当前内容范围

当前共有 11 个行动组、54 种年度行动，覆盖：

- 0～2 岁家庭照护安排（旧版内容，当前交互已移除）；
- 3～6 岁玩耍、交流、观察劳动和入学前练习；
- 小学的功课、家务、同伴和均衡生活；
- 在校与离校青少年的学习、技能、家庭劳动和就业准备；
- 高中/中职及其他青年入口的课程、实训、求职和家庭责任；
- 高等教育的课程、兼职、关系和健康；
- 成年工作、转行学习、关系、照护、健康和储蓄；
- 退休后的活动、家庭、社区和兴趣。

候选集合不仅按阶段和年龄变化，也读取在校/就业/关系状态、具体职业、孩子与年长父母、城乡居住、当前健康值、自然年份和可用于行动的现金。比如城乡儿童看到的劳动观察表述不同；1995 年以后青年可以比较工时、报酬和用工记录；2008 年以后有实际雇佣岗位的成年人可以核对合同与待遇；体力岗位会出现作业恢复行动；有孩子或65岁以上在世父母时会出现对应照护；健康值偏低时会出现降低负荷的恢复方案。所有这类条件都由配置字段筛选并有自动校验。

## 验证

运行：

```powershell
npm run annual:check
npm run causality:check
npm run engine:check
```

`annual:check` 校验配置结构、年龄/状态覆盖、时间和现金约束、地区/时代/健康条件与禁用社会标签；`causality:check` 用同一种子只替换十年的年度行动，检查选择结束数年后的净资产和关系差异，并确认上一年的时间安排不会残留；`engine:check` 完整手动走一生，断言年度行动年龄从 0 岁开始严格逐岁递增、存档可复现、旧存档可迁移、五阶段未选路径进入人生复盘。
