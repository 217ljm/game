# 小学教育年度模拟系统

## 1. 当前成果

小学阶段已经可以从0～6岁状态继续推进到毕业、升入初中、未升入初中、提前离校，或14岁仍未完成小学。首批1978～1982年出生人物会在1984～1996年间经历这一阶段。

系统不预先给人物贴“教育资源普通”或“家庭负担中等”的标签。每年先记录实际家庭收入、食品需要未充分满足月份、病假、家庭劳动、出勤和学习时间，再据此生成入学、继续就读、复读、毕业和升学结果。

## 2. 每年结算顺序

1. 读取当年城乡收入、恩格尔系数与教育统计参考。
2. 更新共同居住成员年龄和各劳动成员的年度收入贡献。
3. 记录家庭人均收入及食品需要未充分满足月份。
4. 记录症状天数、较重症状次数和由此产生的病假；具体诊断保持为空。
5. 未入学人物按目标入学年龄、全国入学率、健康、家庭事实和入学前准备尝试入学。
6. 首次入学时生成五年制或六年制学校、办学形态、授课方式与年度教学天数。
7. 玩家在入学、三年级农忙和毕业年级处理学习、家庭劳动与同伴时间的取舍。
8. 结算实际出勤日、病假、家庭劳动缺课、每周学习与同伴活动时间。
9. 生成内部学习进展值；它只服务于游戏计算，不冒充标准化考试成绩。
10. 根据已发生事实结算继续就读、提前离校、复读、升级或毕业。
11. 小学毕业后按当年的全国小学升初中比例、学习进展、准备时间和家庭收入条件生成升学结果。
12. 所有五项属性变化引用本年度的具体事实编号，并保存未选择的选项。

## 3. 学校与学制

首版生成以下具体办学形态：

- 城镇地方公办小学。
- 单位办小学。
- 农村村办小学。
- 农村乡镇中心小学。
- 半日制或简易小学班。

五年制与六年制并存，比例随入学年份和城乡位置变化。公开资料只能证明两种学制在这一时期并存和逐步过渡，不能给出每个地区、每所学校的精确比例，因此具体抽样比例明确列为可替换建模假设。

系统保存同年全国生师比参考，但不把全国值伪装成具体学校班额或生师比；`specificSchoolStudentTeacherRatio` 在没有校级数据时保持 `null`。

## 4. 已实现的玩家选择

### 入学初期：怎样安排放学后的时间

玩家可以按学校节奏练习、先完成家庭事务，或主要跟着同伴熟悉环境。系统记录每周学习、家庭劳动和同伴活动小时数。

### 三年级农忙：怎样协调家庭劳动与出勤

玩家可以先帮家里再补学习、尽量保护出勤，或与家人分摊任务。该选择会影响缺课、学习进展、心情和关系，并继续影响后续升级与毕业。

### 毕业年级：怎样面对初中通道

玩家可以集中准备升学、平衡学习和家庭事务，或把更多时间用于实际劳动。系统累计具体准备小时数，并在毕业后计算升入初中的概率，而不是直接写成“能力+10”。

每次决定都保存已选选项、未选选项、行为事实和属性变化来源。运行器也可以停在待选节点，供未来游戏界面逐步呈现。

## 5. 历史观测与建模假设

公开观测包括：

- 1984～1996年城乡居民收入与恩格尔系数参考。
- 1984、1985、1987、1990、1991和1995等年份的小学学龄儿童入学率锚点。
- 1987年小学年度巩固率与毕业班毕业率。
- 1991年和1995年小学辍学率，以及用于早年插值的非巩固率代理。
- 1985年及1990～1996年小学毕业生升初中比例。
- 1985、1990和1995年小学全国生师比参考。
- 1986年义务教育法的入学年龄规定。
- 五年制、六年制以及全日制、半日制和简易班并存的制度史资料。

首版可替换假设包括：

- 6岁或7岁目标入学年龄的城乡分布，以及未成功入学后的年度重试。
- 全国入学率如何结合个人健康、家庭收入、食品安排和入学前准备形成个体概率。
- 五年制与六年制、各办学形态的年度城乡分布。
- 全日制与半日/简易班教学天数。
- 症状、病假、家庭劳动时间、出勤和学习进展的生成方式。
- 提前离校、复读和毕业的个体概率。
- 小学升初中全国比例如何结合人物的具体事实形成个体概率。
- 提前离开小学后暂不模拟返校。

所有观测、来源链接和假设编号保存在 `data/calibration/primary_education_1984_1996.json`，选择内容保存在 `data/primary_education_events.json`。

## 6. 阶段结局

- `entered_junior_secondary`：小学毕业并进入下一阶段的初中链。
- `left_school_after_primary`：完成小学，但当年未升入初中。
- `exited_primary_before_completion`：小学未完成便离校。
- `did_not_enter_primary_by_stage_end`：14岁前始终未入学。
- `primary_not_completed_by_age_14`：已经入学，但14岁时仍未完成。

阶段结局均引用导致结果的事实编号，供人生回顾、存档重放和以后接续职业或补充教育路径。

## 7. 运行与验证

```powershell
npm run primary:sample
npm run primary:batch
npm run primary:check
```

指定出生年份和种子：

```powershell
node scripts/simulate-primary-education.mjs --count 1 --year 1978 --seed my-life
```

自动检查覆盖随机种子复现、手动/等待选择、未选分支记忆、长期选择效果、年份连续、事实支持的属性变化、家庭收入核对、入学年龄、两种学制、学校形态、出勤与学习事实、复读与离校边界、毕业和升初中校准、无抽象社会标签以及来源编号可解析。

## 8. 3～12岁季度玩法

小学阶段已经按未入学、低年级、中年级和高年级提供不同活动池。过去形成的学校适应与兴趣探索会以有限加成进入学习进展事实；朋友、家庭、健康与动手经历不会被压缩成单一能力分。完整规则见[3～12岁完整玩法纵向切片](CHILDHOOD_PLAY_SYSTEM.md)。

## 9. 当前边界

- 全国统计只能校准总体方向，尚未加入省级、县级和具体学校供给数据。
- 家庭成员会逐年增长年龄，但兄姐新就业、父母转业和祖辈退休仍需由职业与家庭阶段统一处理。
- 提前离校后的返校、扫盲和成人教育尚未接入。
- 初中阶段已经接收本模块的升学接口；省县和具体学校数据缺口仍然存在。

初中教育和青少年劳动准备已经实现，详见[初中教育与青少年劳动准备系统](ADOLESCENCE_SYSTEM.md)。下一步实现普通高中、职业教育和真实职业机会。
