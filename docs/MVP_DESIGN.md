# 《人生轨迹》MVP 设计说明

> 状态说明：本文保留早期可玩性设计。涉及出身生成、属性来源和事件结算的部分，必须以《社会模拟模型》《1978～2026 时间线》和《核心人生链》为准；在迁移完成前不要直接实现。

## 1. 产品定位

《人生轨迹》是一款轻量文字人生模拟游戏。它不追求还原现实中的所有系统，而是用短事件、明确选择和可分享的结局，让玩家产生“如果重新选择，我的人生会怎样”的体验。

- 平台：抖音小游戏优先
- 屏幕：竖屏
- 单局时长：5～10 分钟
- 目标体验：容易理解、选择有反馈、结局有记忆点、愿意马上重开
- 内容基调：现代生活、轻幽默、温和现实感、不过度说教

## 2. 核心循环

1. 点击“开始人生”。
2. 系统随机生成一种出身，并应用初始属性修正。
3. 玩家按人生阶段经历事件，每次从两个选择中选一个。
4. 选择立即改变属性，也可能记录影响后续事件的标记。
5. 健康归零或到达 80 岁后结算人生。
6. 展示结局、关键选择和五维属性。
7. 解锁结局图鉴，玩家可以立即重新开始。

## 3. 五项属性

所有属性范围均为 0～100，默认初始值为 50，再叠加出身修正。

| 属性 | 含义 | 归零或较高时的影响 |
| --- | --- | --- |
| 健康 | 身体状态和生活节奏 | 归零会提前结束人生 |
| 财富 | 可支配资源和经济积累 | 影响职业、住房与晚年事件 |
| 心情 | 满足感和心理能量 | 影响结局评价及部分选择 |
| 能力 | 学习、工作和解决问题的能力 | 解锁教育与职业机会 |
| 人际 | 亲友关系和社会支持 | 影响陪伴、合作与家庭事件 |

属性变化后必须立即显示动画和数值反馈，不能只在结局时统一展示。

## 4. 人生阶段

| 阶段 | 年龄 | 主要事件 |
| --- | --- | --- |
| 童年 | 0～11 | 兴趣、家庭、朋友、健康习惯 |
| 青少年 | 12～17 | 学业、社交、自我探索 |
| 青年 | 18～29 | 升学、工作、城市选择、亲密关系 |
| 壮年 | 30～44 | 职业发展、家庭责任、生活平衡 |
| 中年 | 45～59 | 转型、父母、健康、重新学习 |
| 晚年 | 60～80 | 退休、陪伴、兴趣、人生回顾 |

## 5. 事件系统

每个事件包含：年龄范围、出现权重、触发条件、正文、两个选择、属性变化和可选的状态标记。

事件抽取规则：

1. 筛选年龄符合的事件。
2. 排除已触发且 `once=true` 的事件。
3. 检查属性和标记条件。
4. 根据 `weight` 加权随机抽取。
5. 如果没有候选事件，使用低权重的通用事件兜底。

首版不加入复杂随机成功率。玩家做出同一选择时应获得一致结果，方便理解因果关系。随机性主要来自出身与事件组合。

## 6. 首版结局

首版至少实现以下六种结局：

- 平凡而完整的一生：没有突出极值时的默认结局。
- 把热爱做成事业：能力和财富较高。
- 有人陪伴的长路：人际和心情较高。
- 松弛而富足的人生：财富和心情都较高。
- 忙碌之后的空房间：财富较高但心情、人际较低。
- 未走完的旅程：健康提前归零。

结局不是简单地评价“成功”或“失败”，而是帮助玩家回看自己长期偏向了什么。

## 7. MVP 范围

必须实现：

- 随机出身
- 五项属性
- 年龄与人生阶段
- 事件和双选项
- 条件事件与状态标记
- 六种结局
- 结局图鉴的本地存档
- 再来一次
- 基础音效和数值动画

暂不实现：

- 登录、排行榜和好友系统
- 云存档
- 玩家自由输入姓名
- 广告和内购
- 房屋装修、地图移动和角色自由行动
- 多人或实时系统

## 8. 内容安全边界

- 不使用未授权的明星、影视、动漫、字体、音乐或表情包。
- 不把算命、占卜或迷信作为核心玩法。
- 不出现赌博、毒品、违法犯罪教学或低俗诱导内容。
- 不设计一对多恋爱关系。
- 不强迫玩家分享、关注或提供个人信息。
- 首版不允许玩家输入自定义文本，避免额外的内容审核与隐私风险。

## 9. 第一版验收标准

- 玩家两次点击以内开始一局。
- 一局能够从出身完整进行到结局。
- 至少出现 12 个选择事件。
- 每次选择都能看见属性变化。
- 至少能触发三种不同结局，完整内容目标为六种。
- 结局被记录到本地图鉴。
- 不刷新页面也能“再来一次”。
- 不存在无可用事件导致流程中断的情况。
