# 人生轨迹（工作名）

一款正在重构为正式游戏表现层的中文竖屏季度回合制人生模拟游戏。玩家出生于 1978～1982 年，通过具体生活行动形成属性、兴趣、关系和人生方向，再走过教育、工作、迁移、住房、健康、退休与死亡。

> “人生轨迹”是研发工作名。申请软著、创建正式小游戏和发布前仍需确定正式名称。

> **最新产品方向已冻结：** 正式产品采用“确定性人生 Core + Phaser/Canvas 2D 游戏表现层 + 少量 DOM 工具层”。参考《中国式人生》的游玩语法，但不照抄视觉或内容；不做场景移动、地图、热点寻找，也不再把仪表盘、网页表单、背景图或文字卡当作主玩法。产品、玩法、游戏表现、技术边界、分阶段开发和验收的唯一基线是 [《1978—一生》季度回合制人生模拟器开发总纲 v5.0](docs/QUARTERLY_LIFE_SIMULATOR_MASTER_PLAN.md)。

当前 `public/index.html`、`public/app.mjs`、`public/styles.css` 仍是旧 DOM 原型，只用于验证 Core、存档和迁移，不是目标客户端。新增正式主玩法不得继续堆入这三个文件。

## 运行现有验证原型

需要 Node.js 18 或更高版本，不需要安装第三方依赖。

```powershell
npm run play
```

打开 `http://127.0.0.1:4173`。浏览器会在每次选择后自动保存；相同种子和选择会精确复现同一人生。这个入口只代表现有逻辑可运行，不代表正式游戏画面已经完成。

详细操作、存档口径和界面说明见 [可玩版本说明](docs/PLAYABLE_APP.md)。

开发测试无需每次从出生手动点击：打开 `http://127.0.0.1:4173/?debug=1` 可从出生自动回放到指定年龄、季度或关键事件，并使用独立调试存档。完整说明见 [人生调试台](docs/DEBUGGING.md)。3～12岁的详细玩法见 [3～12岁完整玩法纵向切片](docs/CHILDHOOD_PLAY_SYSTEM.md)。

## 当前实现基础

- 已完成六项终身属性、短期状态、隐藏潜能与小数成长残差；属性使用同一套 0～100 绝对标准，不随年龄重置或换算。
- 已完成季度 12 格时间、动态精力、最多 3 点透支、三档行动强度和 v5 确定性存档迁移。
- 已完成固定责任来源、主动休息、三个月实际执行、事件中断降速和不可执行计划返回提醒；季度结果不再是一次点击后瞬间结算。
- 旧 DOM 主界面和轻场景实验都不是目标成品，也不得继续扩充为正式主流程。
- 下一正式目标是把 1984 年 6 岁 Q1～Q4 迁入游戏运行时：角色与状态持续可见，行动加入后不消失，只有一个季度推进动作，并通过动画、声音和结果状态表现三个月执行、事件打断、长期成长与 Q4 增龄。
- 390×844 Chrome 自测必须覆盖资源不足、事件打断、Q4 增龄、存档恢复和一段 60～90 秒无剪辑实机流程；背景图、文字卡或按钮能点不算完成。

## 已实现范围

- 1978～1982 年出生档案，保存城乡、家庭成员、父母职业与具体收入事实。
- 0～6 岁、小学、初中、高中/中职、高等教育及教育退出路径。
- 第一份工作、失业、换岗、晋升、合同、工时、工资、迁移和时代冲击。
- 伴侣、一个孩子、父母照护、住房、房贷、储蓄、债务与家庭年度账本。
- 父母按出生年继续变老；孩子按年龄经历成长阶段，家庭照护选择形成实际相处时数与累计支持记录。
- 症状日、慢性健康事件、退休、养老金、死亡和人生复盘。
- 健康、体能、智力、外表、社交、意志六项终身可见属性；心情、压力、疲劳、疾病、伤势和季度精力作为短期状态单独计算。出生健康储备按历史锚点分层，不把健康新生儿显示为默认半血，也不冒充临床评分。
- 每个自然年固定四个季度，每个季度内部生成三个月进度记录；幼年由家庭连续安排，学龄后逐步增加玩家操作量，无变化计划可延续和快速结算。
- Core 能以当前年龄、身份、现实责任和过去经历生成行动池，并支持尝试、常规或重点投入。旧 DOM 页面只是这些能力的验证外壳，正式表现将迁入独立游戏运行时。
- 整个人生分为“认识世界、家庭与学校、开始选择方向、进入社会、建立自己的生活、守住与改变、后来的日子”七章；每章同时追踪眼下要维持、正在积累和想要靠近的三条人生课题。
- 理解求知、动手实践、表达创造、关系生活、身体节律、工作保障六种人生方向由实际行为、兴趣时数和经历逐步显现，可以持续、改变或被放下，不在出生时预设职业或成功路线。
- 6、9、12、15、17岁会发生五次“经历兑现”事件：实际兴趣时数、成长线、健康、能力、家庭参与和持续人物决定哪些选择可执行；选择同时写明所得与代价，并可解锁跨季度行动、人物共同记忆及教育/技能/就业准备。18岁生成从早期行为追溯到成年入口的因果复盘。
- 1 岁有 6 种眼前反应，2 岁有 7 种自主尝试；声音模仿、节奏、物件观察、分享、涂画、家务和动作游戏会分别留下兴趣、认知能力、健康、关系与成长线影响。
- 3 岁以后同一季度可组合多项生活活动；学龄后通常选择 2～4 项，学习、娱乐、朋友、家庭、健康与工作不再被压成互斥的“唯一主行动”。
- 3～12岁有7个分龄/分学籍/分年级活动池和52项详细活动；每项会结算地点、参与人物、三步过程、实际小时、回应与结果。
- 兴趣探索、同伴朋友、家庭参与、学校适应、活动休息、动手独立形成6条连续成长线和18个节点，过去经历会解锁后续活动并有限进入小学学习结算。
- 每个季度记录具体活动、每周投入、约 13 周总时数、未分配的普通生活时间、现金成本与行动来源；支持延续、维持到年底和仅在不可执行时提醒。
- 启蒙接触会累积为兴趣萌芽、稳定爱好和长期爱好；未继续投入的兴趣会逐渐淡化，既有兴趣也会解锁延续活动。
- 每季度可能发生一件符合年龄、年代、身份和本季活动的随机生活事件；事件使用独立种子、冷却期和明确后果，不会因点击顺序反复抽取。
- 每次长期选择保留未选项；结局可以回看“没有走过的历程”。
- 童年玩伴、同学、培训伙伴、工作联系人等虚构人物会跨年份保留，并随联系或疏远改变。
- 历史观测只到 2025 年；2026 年以后在界面明确标为中性情景，不冒充历史或预测。

系统不保存“教育资源普通”“家庭负担中等”“收入稳定性偏低”一类人工等级。收入稳定与否由实际岗位、工作月份、合同、换岗和连续年度收入记录产生。

npm run youth-mainline:check

npm run annual:check
npm run social:check

```powershell

npm run life:batch
```

## 当前产品边界

这是本地单机纵向原型，不含账号、云存档、支付、广告、排行榜、服务端和平台 SDK。发布为抖音小游戏或其他正式产品前，还需要适配目标平台、内容审核、隐私政策、软著与主体/备案要求；这些发布工作不应与核心模拟正确性混在一起。
