# 初中教育与青少年劳动准备系统

## 1. 当前成果

小学阶段的所有结局现在都能继续推进：已经升入初中的人物经历三年制初中、教育现金支出、出勤、毕业考核和高中阶段分流；没有升入初中或提前离开学校的人物经历家庭劳动、自学、技能观察，并在16岁以后形成下一阶段方向。

首批1978～1982年出生人物在1986～2000年之间进入这一阶段。具体人物不会重新抽取一次全国初中入学率：小学结局已经记录了是否升入初中，全国初中毛入学率只作为时代背景和总体校准参考，避免同一件事被随机决定两次。

## 2. 两条入口

### 初中在读路径

入口必须是小学阶段的 `entered_junior_secondary` 结局。系统生成一所具体办学形态的初中，并逐年记录：

- 学校形态、三年制学制和年度教学日。
- 同年全国生师比参考；没有校级数据时，具体学校生师比保持 `null`。
- 家庭年度收入、教育现金支出及支出占家庭收入比例。
- 症状、病假、家庭劳动缺课、教育支出相关缺课和实际出勤日。
- 每周学习、家庭劳动和同伴活动时间。
- 0～100的内部学习进展值；它不是复原出来的统考或中考成绩。
- 继续就读、提前离校、升级、复读、毕业和高中阶段去向。

毕业年会记录一次本地毕业或升学考核代理事实。由于缺少不同地区、不同年份的考试规则，标准化考试总分、分科成绩和地区规则保持为空，系统不会伪造一套全国统一中考。

### 非在校路径

小学毕业未升入初中、小学提前离校、未入小学或初中提前离校的人物都会进入这一入口。

未满16岁时只记录：

- 家庭生产或家务小时。
- 自学读写小时。
- 观察和练习技能的小时。
- 同年全国就业结构与职工平均工资参考。

这些活动不会创建用人单位、工资、劳动合同或正式就业关系。1991年《禁止使用童工规定》曾为尚不具备初中义务教育条件的农村贫困地区13～15岁少年保留受省级办法严格限制的辅助劳动例外；由于人物目前没有省份、贫困地区认定和地方办法数据，首版不生成这项例外，并在年度事实中明确记录。16岁时，人物可以形成参与家庭经济活动、寻找入门工作、参加短期训练或继续自学的下一阶段方向；本阶段只记录训练、联系和准备，不宣称工作已经找到。

## 3. 年度结算顺序

1. 更新共同居住成员年龄。
2. 读取当年城乡收入和恩格尔系数参考。
3. 延续家庭相对收入位置，结算每个劳动成员的年度收入贡献。
4. 记录食品需要未充分满足月份和青少年症状、病假事实。
5. 在校人物结算学校、玩家选择和教育现金支出。
6. 结算出勤、学习进展、继续就读、升级、复读或毕业。
7. 初中毕业人物依据同年全国升学率、个人准备、学习、收入和教育支出进入普通高中、职业教育或非在校路径。
8. 非在校人物结算家庭劳动、自学和技能练习。
9. 达到16岁的人物生成下一阶段劳动或训练准备接口。
10. 五项属性变化引用本年度已经存在的事实编号，并保存未选择选项。

## 4. 玩家选择

### 初中路径

- 入学后怎样分配学习、家庭劳动和同伴时间。
- 二年级面对书本、路费或住宿等现金支出时，是保留完整安排、借用资料，还是增加家庭劳动。
- 毕业年重点准备普通高中、职业教育，还是毕业后参加劳动。

毕业年选择会分别累计学术、职业和劳动准备小时。它既影响是否进入高中阶段，也影响进入普通高中或职业教育的条件概率。

### 非在校路径

- 离开学校后参加家庭生产、保持自学，或跟着熟人观察一门手艺。
- 16岁后准备留在家庭经济活动、寻找入门工作、参加短期技能训练，或继续自学。

所有决定保存已选选项、未选选项、行为事实和属性变化来源。幼年和小学阶段的未选分支也继续保留在状态中。

## 5. 历史观测与假设边界

公开观测包括：

- 1986～2000年城乡居民收入与恩格尔系数。
- 1990～2000年初中毛入学率。
- 1991～2000年若干年度的初中在校生辍学率。
- 1990～2000年初中毕业生升入高中阶段的比例。
- 1992～2000年全国初中生师比。
- 1990、1995和1999年高中阶段职业教育结构参考。
- 1991、1995和1999年三次产业、城镇私营个体及乡镇企业就业结构。
- 1990、1995和2000年职工年平均工资。
- 1991年禁止使用童工规定、其中家庭劳动边界与地方性农村辅助劳动例外，以及1995年起实施的劳动法。
- 1996年起实施的职业教育法及初中后教育分流制度节点。

首版可替换假设包括：

- 家庭相对收入位置和父母原职业的年度延续。
- 城乡初中办学形态、教学日和教育现金支出尺度。
- 青少年常见症状和病假。
- 内部学习进展、复读和毕业概率。
- 全国辍学率与升学率如何结合个人事实形成个体概率。
- 用高中阶段职业教育在校生占比近似新入学方向比例。
- 未满16岁非在校人物的家庭劳动、自学与技能练习时间。
- 16岁时只形成劳动或训练准备，不在本阶段抽取实际工作。
- 暂不模拟初中复学。

所有观测和来源保存在 `data/calibration/adolescence_education_1986_2000.json`，事件内容保存在 `data/adolescence_events.json`。

## 6. 阶段结局

- `entered_academic_senior_secondary`：进入普通高中。
- `entered_vocational_secondary`：进入高中阶段职业教育。
- `prepared_for_family_economic_activity`：准备继续参与家庭经济活动。
- `prepared_for_entry_job_search`：准备寻找入门工作。
- `prepared_for_short_vocational_training`：准备参加短期技能训练。
- `continued_self_study_after_16`：16岁后继续自学并延后决定。
- 阶段上限结局：18岁仍未完成初中，或劳动方向仍未解决。

每个结局均引用产生它的事实编号。高中阶段入口、劳动与训练准备入口现在会直接交给已实现的青年阶段模块；该模块继续生成高中/中职学习事实、培训、自学、具体候选岗位、合同、工时和实际收入，再进入成年生命周期。

## 7. 运行与验证

```powershell
npm run adolescence:sample
npm run adolescence:batch
npm run adolescence:check
```

指定出生年份和随机种子：

```powershell
node scripts/simulate-adolescence.mjs --count 1 --year 1978 --seed my-life
```

自动检查覆盖：随机种子复现、两条路径的手动和等待选择、跨阶段未选分支记忆、升学与分流反事实、年份连续、属性事实引用、家庭收入核对、教育现金支出、初中出勤与毕业、辍学和升学校准、普通/职业方向、未满16岁无正式就业、全国工资不赋给个人、16岁准备不伪造成工作，以及全部来源编号可解析。

## 8. 当前边界

- 暂无省、县、具体学校距离、当地收费和招生规则数据。
- 初中毕业考核只保留内部进展和缺失字段，不复原不存在的全国统一试卷。
- 父母转业、下岗、退休及家庭成员新就业仍需统一职业模块处理。
- 初中离校后的复学、成人初中与扫盲教育尚未接入。
- 下一阶段需要分别实现普通高中、职业中学/中专/技校、短期训练和真实就业机会；准备方向不能直接等于实际录取或就业结果。
