# 0～18岁主线兑现系统

## 目标

儿童行为不能只改变属性条。玩家过去实际做过的事情，会在6、9、12、15、17岁进入新的生活场景：有人注意、时间不够、环境变化、承担真实任务，以及把经历用于成年入口。未达到条件不是失败，而是只能选择当时现实中可走的其他道路。

## 五个兑现节点

| 年龄 | 场景 | 主要判断 |
| --- | --- | --- |
| 6岁 | 第一次被别人认真看见 | 兴趣时数、成长线和最近做过的事 |
| 9岁 | 功课、家庭与想继续的事发生冲突 | 连续投入、健康和家庭参与 |
| 12岁 | 把童年积累带进新阶段 | 方向连续性，以及是否愿意继续、分享或改换 |
| 15岁 | 承担一项有真实结果的任务 | 连续投入、健康、时间与人物关系 |
| 17岁 | 把经历整理为成年生活入口 | 能力、方向、持续人物、教育和工作准备 |

每个选项必须同时展示所得和代价。条件不足的选项保留在界面中并说明原因，例如健康不足、过去投入太少、家庭参与不足、当前方向不匹配，或没有能证明共同经历的可信人物。

## 可兑现的结果

系统读取理解求知、动手实践、表达创造、关系生活、身体节律和工作保障六种动态方向。选择可能产生：

- 新的跨季度行动，重新进入当前年龄行动池；
- 兴趣、属性和儿童成长线的有限变化；
- 学业、技能、转段或就业准备的实际数值；
- 一名由共同活动产生的持续人物及记忆；
- 后续季度的继续投入记录；
- 数年后关键事件中的延迟回响；
- 被主动放下、以后仍可重新捡起的方向。

这些结果不会直接指定职业、学历或收入。后续道路仍由原有升学、岗位、家庭现金、健康和时代规则结算。

## 18岁复盘

到达18岁后，成长页生成可展开的因果链。每个节点显示当年年龄、此前证据、玩家选择、所得、代价、后来继续投入的季度数，以及进入该经历的人物。年表增加“0—18岁经历复盘”节点，人生结局也保留关键兑现次数。

## 调试与验收

调试台的关键事件目录可以直接寻找五个兑现事件的合法前史，15岁和17岁已加入关键年龄快捷入口。导出报告包含完整兑现状态、解锁行动、延续次数和18岁复盘。

```powershell
npm run youth-mainline:check
npm run debug:check
npm run browser:check
```

专项验收验证五个年龄事件、真实前史证据、条件锁定、每项选择的所得与代价、解锁行动回到季度池、延迟回响、持续人物和18岁因果复盘。
