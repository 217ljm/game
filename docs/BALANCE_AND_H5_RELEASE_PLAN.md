# 《1978—一生》平衡与 TapTap H5 发布实施规范

状态：阶段 G 已完成实现与验收  
生效日期：2026-08-23  
上位规范：`docs/FULL_GAME_REBUILD_V2.md`

## 1. 目标

阶段 G 把“能玩完整一生”升级为“点击量可承受、内容不机械重复、异常可恢复、可形成静态 H5 发布包”。本阶段不改变已经校准的历史统计锚点，只调整交互节奏、内容推荐、客户端恢复和发布工程。

## 2. 平衡门槛

### 2.1 每年典型主动交互

| 年龄 | 主动季度 | 年度确认 | 典型合计（不含事件） |
|---|---:|---:|---:|
| 0 岁 | 0 | 1 | 1 |
| 1 岁 | 1 | 1 | 2 |
| 2～11 岁 | 2 | 1 | 3 |
| 12～59 岁 | 4 | 1 | 5 |
| 60+ | 2 | 1 | 3 |

随机事件与关键节点可增加选择，但普通完整人生目标为平均每年不超过 6 次需要回应的交互。已有“延续上季度”“维持到年底”“只在不可执行时提醒”必须始终可用。

### 2.2 行动池与重复

- 普通合法状态至少 8 项可执行，12 岁以后目标至少 10 项；
- 同一季度推荐区只显示 3 项，完整池分页每次 6 项；
- 普通行动连续 2 季后降低自动推荐权重，但不禁止玩家主动延续；
- 稳定爱好与主线兑现行动不按普通重复惩罚处理；
- 同一随机事件按事件自身 `cooldownYears` 冷却；
- 自动人生相邻季度“全部行动完全相同”的比例目标低于 55%，其中玩家选择保持计划的季度单独统计，不视为内容失败。

### 2.3 数值与结局

- 六项属性始终为终身绝对 0～100；
- 健康、疲劳和压力不能因单一普通行动在一季内产生极端跳变；
- 不存在唯一成功结局；批量人生至少能形成 4 类以上生活原型；
- 相同种子和相同选择必须得到相同结果；
- 不同早期选择至少能在属性、兴趣、关系、资产或后续机会中形成可测差异。

## 3. 异常恢复

正式存档使用：

- 主存档 `people-life:active:v5`；
- 上一次有效存档 `people-life:backup:v5`；
- 表现设置 `people-life:presentation:v1`；
- UI 路由 `people-life:ui:v1`。

每次写入新主存档前，先把现有有效主存档保存为备份。读取时依次尝试主存档、备份、旧版本；损坏条目单独移除，不影响其他条目。成功使用备份后恢复主存档并提示玩家。调试存档使用独立主/备份键，不接触正式人生。

## 4. H5 发布包

`npm run h5:build` 生成 `dist/`：

- 根 `index.html`；
- `public/` 客户端、样式、字体和美术；
- `src/` 确定性核心与页面 presenter；
- `data/` 校准数据与内容；
- `manifest.webmanifest`；
- `release-info.json`。

发布包不得包含调试截图、测试脚本、开发文档、原始生成图或 npm 缓存。根入口使用 Hash 路由，刷新任意游戏页面不依赖服务器重写。

## 5. TapTap H5 运行约束

- 竖屏优先，首要尺寸 390×844；
- 使用 `viewport-fit=cover` 和安全区变量；
- 不依赖第三方登录、外部 CDN、跨域字体或运行时下载；
- Web Audio 必须由用户手势激活，失败时静默降级；
- 振动、Service Worker、下载和分享能力均按可用性检测；
- 模拟核心不读取系统时间和网络响应，保证可重放；
- 未来接入 TapTap 登录、实名、防沉迷和支付时使用平台适配器，不把 SDK 调用写入模拟核心。

## 6. 开发顺序

1. G1：互动节奏、候选池、重复和结局分布检查；
2. G2：主/备份存档恢复；
3. G3：PWA/H5 元数据与静态构建；
4. G4：发布包合同与真实浏览器冒烟；
5. G5：全量 `check`、`browser:check`、`h5:build`、`h5:check` 汇总。

## 7. 完成条件

只有以下命令全部通过才标记阶段 G 完成：

```text
npm run balance:check
npm run recovery:check
npm run presentation:check
npm run check
npm run browser:check
npm run h5:build
npm run h5:check
```

发布包完成不等于平台审核已通过；平台账号、版号/备案、隐私、实名和内容合规材料属于正式上线前的外部提交事项，不能由代码测试代替。
