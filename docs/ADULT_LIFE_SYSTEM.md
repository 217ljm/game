# 成年人生系统

## 范围

`src/simulation/adult-life-simulator.mjs` 接收青年阶段的毕业或首份工作状态，逐年推进到死亡，覆盖：

- 普通高等教育：三年专科、四年本科、专业方向、年度费用、退出和毕业；
- 劳动：求职、具体岗位、行业、单位性质、合同、工时、收入、失业、换岗和晋升；
- 家庭：伴侣的教育、职业和收入，一个孩子，以及父母照护和死亡；
- 住房与财务：租住、家庭住房、购房尝试、首付、房贷、支出、储蓄、债务和净资产；
- 健康与晚年：症状日、非诊断性慢性健康事件、退休年龄估算、养老金和死亡；
- 人生复盘：职业史、最高教育、住房、家庭、最终资产、五项属性和全部未选路径。

## 现实数据与游戏假设

校准文件为 `data/calibration/adult_life_1992_2025.json`。其中：

- `observations` 保存统计口径、年份、数值与 `sourceId`；
- `sources` 保存国家统计局、国家卫健委、全国人大、国务院和教育部等来源页面；
- `assumptions` 保存个体层无法由宏观统计直接推出的概率和公式；
- `scenarios` 只用于 2026 年以后，`SCENARIO_BASELINE_2026_PLUS` 明确不是预测。

宏观锚点包括城乡居民收入、城镇单位工资、三次产业就业结构、城镇化、2024 年人均预期寿命，以及住房制度、高校扩招、劳动合同法和渐进式退休等政策节点。宏观均值只约束生成分布，不会把“全国平均工资”直接写成某个角色的收入。

无法可靠知道的内容保持未知：系统不会伪造学校名称、单位名称、具体城市、住房地址、疾病诊断或房屋成交价。住房缺少城市和面积时，用收入倍数生成现金流，并在数据中标为假设。

## 年度结算顺序

每个成年年份按相同顺序推进：时代与数据口径、教育或工作、伴侣和家庭、住房、收支与资产、健康、长期事件选择、死亡与退休。所有属性变化都能回到同年的事实；财富属性会根据净资产及当年居民收入参照重算。

玩家做选择时，系统只记录所选项 ID。候选工作同时带有岗位、行业、单位性质、工时和预计年收入，因此“换一份工作”不是抽象按钮。没有选择的具体候选项会完整进入 `untraveledPaths`。

## 确定性与测试

相同人物档案、青年状态、随机种子和选择映射会得到完全相同的成年人生。运行：

```powershell
npm run adult:check
```

当前校验用 5,000 人检查：年龄边界、教育与工作衔接、工作候选数量、工资和家庭账本恒等式、失业与换岗、伴侣和孩子、购房、退休、死亡分布、五项属性范围、来源引用、情景标记和未选路径保存。

这不是人口预测模型。死亡、伴侣、生育、晋升和个体工资冲击都属于透明的游戏假设，目标是形成可解释且近似现实的个人历程，而不是复刻某一真实人物。
