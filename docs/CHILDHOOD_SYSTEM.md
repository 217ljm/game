# 0～6岁年度模拟系统

## 1. 当前成果

出生档案现在可以按年推进到6岁。每年不是抽取一段孤立文案，而是依次更新社会环境、家庭成员、劳动、收入、照护、健康和玩家行动，再由已经记录的事实改变五项游戏属性。

模拟覆盖出生于1978～1982年的人物，因此儿童阶段历史范围为1978～1988年。

## 2. 每年结算顺序

1. 读取当年城乡收入、食品支出参考和已经生效的制度。
2. 更新共同居住成员年龄。
3. 符合条件的农村第一产业家庭可能从集体劳动转为家庭承包经营。
4. 根据母亲年龄、已有子女和城乡条件判断是否有弟妹出生。
5. 0～2岁儿童可能接触当年的计划免疫服务。
6. 记录本年常见症状事件、持续天数和照护者需要投入的照护天数。
7. 更新父母劳动月份，结算家庭具体收入并核对到每个劳动成员。
8. 根据实际人均收入、同年同城乡参考和食品支出比例记录食品需要未充分满足月份。
9. 结算儿童生存结果。
10. 从上述事实更新健康、财富、心情、能力和人际。
11. 在3岁、5岁和6岁产生玩家行动选择，并保存未选择的选项。
12. 6岁时生成下一阶段入学环境，但不提前替玩家决定是否、何时入学。

## 3. 已实现的玩家选择

### 3岁：大人忙着的时候

玩家决定孩子把时间主要放在照看者、附近同伴或观察成人劳动上。系统记录每周交谈、同伴游戏或观察劳动的具体小时数。

### 5岁：看不懂的字和数字

玩家可以询问大人、自己比画或回去玩耍。系统记录每周提问、练习或同伴游戏的具体次数与小时数。

### 6岁：入学前的准备

玩家可以练习字和数字、学习家庭事务或认识未来可能一起上学的孩子。入学本身由下一阶段的学校供给、年龄规定和家庭事实决定。

每次决定保存：

- 玩家实际选择的选项。
- 当局没有选择的选项。
- 选择产生的具体行为事实。
- 属性变化所引用的事实编号。

运行器支持停止在首个待选事件，供未来界面逐步呈现；批量测试时则按配置权重自动选择。

## 4. 历史观测与建模假设

公开观测包括：

- 1978～1988年城乡居民收入与恩格尔系数。
- 1981年婴儿死亡率37.6‰。
- 1981年育龄妇女一般生育率82.4‰。
- 1978年开始实施计划免疫，1988年以省为单位“四苗”接种率达到85%目标。
- 1980、1985、1986、1987和1990年小学学龄儿童入学率锚点。
- 1986年义务教育法及规定的6岁、条件不足地区7岁入学年龄。
- 1983年农村大包干联产承包责任制94.5%农户覆盖锚点。

首版可替换假设包括：

- 出生时相对收入位置的年度延续和随机波动。
- 父母年度劳动月份与照护天数的收入分配影响。
- 常见症状事件频率、较重症状比例以及1～6岁死亡概率。
- 以收入和食品支出参考生成食品需要未充分满足月份。
- 1978～1988年城乡计划免疫服务接触扩散曲线。
- 由一般生育率调整得到的具体家庭弟妹出生概率。
- 农村责任制逐年扩散曲线。
- 三个幼年选择事件及其行为和属性效果。

所有数值、来源链接和假设编号保存在 `data/calibration/childhood_1978_1988.json` 与 `data/childhood_events.json`。

## 5. 生存和健康边界

幼年死亡是一条可发生的真实人生结局，但当前公开数据只足以校准概率，不足以给每个个体分配可信死因。发生时系统记录“致死幼年健康事件”，具体诊断和医学确认死因保持为空，并明确说明数据缺口。

普通幼年疾病同样只记录发热、呼吸或消化道症状类事件的次数和持续天数，不伪造具体诊断。

## 6. 运行方法

```powershell
npm run childhood:sample
npm run childhood:batch
npm run childhood:check
```

指定出生年份和种子：

```powershell
node scripts/simulate-childhood.mjs --count 1 --year 1978 --seed my-life
```

同一个出生种子和儿童阶段种子会得到相同结果。

运行所有模块检查：

```powershell
npm run check
```

## 7. 验证范围

自动检查覆盖：

- 随机种子可复现。
- 年份与年龄连续。
- 手动选择、等待选择和未选择分支记忆。
- 每项属性变化均引用同一年度存在的具体事实。
- 家庭成员收入贡献与家庭账本一致。
- 婴儿死亡率回到公开观测锚点附近。
- 1～6岁死亡率遵循明确标注的首版假设。
- 弟妹出生频率不会消失或失控。
- 农村家庭承包经营扩散到观测锚点。
- 计划免疫接触率沿城乡代理曲线变化。
- 没有新增弟妹的家庭，其平均相对收入位置保持可解释的连续性。
- 不出现“家庭负担中等”“收入稳定性偏低”等人工社会等级。
- 所有来源和假设编号均可解析。

## 8. 3～12岁季度玩法

年度家庭、健康与生存结算之上已经接入分龄季度玩法。3～6岁活动会保存实际地点、参与者、过程、实际小时、回应和结果，并推进可跨入小学的六条成长线。完整规则与验证见[3～12岁完整玩法纵向切片](CHILDHOOD_PLAY_SYSTEM.md)。
