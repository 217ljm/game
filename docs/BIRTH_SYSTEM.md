# 出生系统（1978～1982）

## 1. 已实现范围

出生系统是第一个可运行的社会模拟模块。输入一个随机种子，可生成并回放同一份出生档案；未指定年份时，1978～1982 年按“年末人口 × 当年出生率”估算的出生人数加权抽样。

档案目前包含以下具体事实：

- 出生日期、性别、城镇或乡村出生环境。
- 出生时共同居住人数、父母、年长兄姐和共同居住祖辈。
- 有经济活动的家庭成员、行业、具体职业、单位性质、劳动形式和当年劳动月份。
- 每位劳动成员计入家庭账本的年度收入贡献。
- 家庭年度总收入、人均收入、当年同口径统计均值和恩格尔系数参考值。
- 住房占有或使用方式。
- 从事实派生的五项可见游戏属性及其计算依据。
- 本次生成使用的公开统计来源、建模假设和尚未校准的字段。

档案中不保存“家庭负担中等”“收入稳定性偏低”等社会标签。后续的家庭压力或收入波动只能通过连续年份的收入、劳动、支出、照护和债务事实计算。

## 2. 生成顺序

1. 按估算出生人数选择出生年份。
2. 根据该年城镇、乡村人口及各自出生率选择出生环境。
3. 根据出生人口性别比生成性别。
4. 生成出生日期和共同居住人数。
5. 生成父母、年长兄姐和共同居住祖辈。
6. 按城乡条件生成父母行业、职业、单位性质和劳动月份。
7. 从以官方城乡人均收入为均值的分布中生成具体家庭收入。
8. 将收入核对分配到有劳动事实的家庭成员。
9. 生成住房事实。
10. 派生五项可见属性，并写入来源与缺项。

## 3. 数据口径

### 3.1 公开统计观测

- 1978～1982 年人口、城乡结构和总人口性别结构。
- 1978～1982 年人口出生率；1978～1981 年城乡出生率。
- 1978～1982 年城镇居民人均可支配收入、农村居民人均纯收入和恩格尔系数。
- 1982 年家庭户均 4.4 人。
- 1982 年出生人口性别比 108.47。
- 1981 年婴儿死亡率 37.6‰，用于出生健康储备分层后的总体风险校准。
- 1978 和 1985 年三次产业就业结构锚点。
- 1978 年城镇国有、集体单位就业合计占比。
- 1984 年城镇住房产权结构。
- 1983 年农村大包干联产承包责任制农户占比。

完整数值、来源链接和口径说明保存在 `data/calibration/birth_1978_1982.json`。

### 3.2 可替换的首版假设

- 新生儿家庭规模分布只用来逼近全体家庭户均 4.4 人，两者不是完全相同的人群。
- 1978～1981 年暂用 1982 年出生人口性别比。
- 1982 年城乡出生率保持 1981 年城乡比值，再缩放至当年全国出生率。
- 出生月日暂按均匀分布生成；父母年龄、额外家庭成员构成、行业的城乡条件分布、具体职业和劳动月份尚未由微观数据校准。
- 家庭人均收入用对数正态分布生成；城乡离散程度是首版参数。
- 1978～1982 年城镇住房暂用 1984 年观测作近邻代理。
- 农村家庭联产承包采用连接改革起点与 1983 年观测值的扩散曲线，不表示各地区同步。
- 出生健康储备分为强健、一般和脆弱三类；分数只用于游戏可见状态，类别风险乘数的加权均值为 1，使总体婴儿风险仍回到 37.6‰，不推断体重、疾病或诊断。

每项假设都有稳定编号 A01～A13。生成档案只记录实际使用的假设编号，方便以后替换数据而不改变存档结构。

## 4. 重要字段说明

- `household.finance.annualIncomePerPersonYuan` 是模拟家庭的具体值，不是直接复制全国均值。
- 城镇使用历史统计中的“人均可支配收入”，农村使用“人均纯收入”；两者不可当作完全相同口径比较。
- `annualIncomeContributionYuan` 是该成员计入家庭账本的收入贡献，不等同于统计意义的职工平均工资。
- `mainEarnerSector` 用于家庭主行业的批量校验；家庭成员仍各自保存工作事实。
- `visibleStats.wealth` 由同年同城乡的相对人均收入派生。
- `person.healthAtBirth` 保存健康储备分数、风险类别和个体化婴儿期建模概率；`visibleStats.health` 直接显示该储备分数。它是经群体风险校准的游戏量表，不是临床评分或诊断。
- 心情和人际在缺少个人经历时从中性值开始，能力从 0 开始积累；中性值不代表真实评价。

## 5. 暂不生成的数据

以下内容没有可靠校准时保持 `null`，不会用文字等级替代：

- 省份、县市和具体出生地点。
- 户籍类别。
- 出生体重、疾病、诊断和其他医学事实；健康储备分数不能代替这些字段。
- 父母及其他成员学历。
- 住房面积和住房成本。
- 存款、生产资料价值和债务。

## 6. 运行方法

项目不依赖第三方包，安装 Node.js 后即可运行。

```powershell
npm run birth:sample
npm run birth:batch
npm run birth:check
```

也可以指定年份和种子：

```powershell
node scripts/simulate-births.mjs --count 1 --year 1978 --seed my-life
```

相同的 `--year` 与 `--seed` 会返回同一份出生档案。

## 7. 批量校验结果

2026-08-12 使用 100,000 份档案完成校验：

- 共同居住人数均值为 4.388，校准目标为 4.4。
- 男性占 52.032%，与 108.47 的出生人口性别比换算值一致。
- 城镇出生家庭占 15.559%；这不是城镇总人口占比，因为城乡出生率不同。
- 各年城乡模拟人均收入均值回到各自统计均值附近。
- 城镇住房分布、出生年份权重、主行业分布和成员收入核对通过误差阈值。
- 档案中不存在被禁止的人工社会等级标签。

## 8. 下一模块

下一步应从出生档案推进到 0～6 岁：逐年结算父母工作、家庭收入、家庭成员变化和婴幼儿健康事件，并让 1978～1982 年的农村改革进程真正改变家庭生产方式和收入来源。省级地理层应在需要地区差异的教育、医疗事件进入前补齐。
