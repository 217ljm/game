# 跨年人物关系系统

## 目的

年度行动不只改变五项属性，也会让玩家认识具体的人。童年玩伴、小学和中学同学、培训伙伴、大学同学、工作中认识的人与成年朋友会保存在同一条人生轨迹中，并在后续年份继续出现。

这些姓名和经历全部由游戏生成，界面明确标注为虚构人物，不借用现实人物身份。未来若加入历史人物，只能作为公开历史背景或独立体验内容，不能与本系统生成的人物混淆。

## 生成与延续

人物目录位于 `data/social_character_catalog.json`，运行逻辑位于 `src/simulation/social-character-system.mjs`。

- 每个教育或生活阶段都有对应人物角色；
- 入学等明确场景会保证认识至少一位同学；
- 选择陪伴同伴、维持关系、拓展联系或参加社区活动时，可能认识新人或联系已有的人；
- 每个人保存相识年份、相识年龄、最近联系年份、共同经历年数与亲近度；
- 没有保持联系时，亲近度按年缓慢下降；主动联系带来的增长高于自然下降；
- 人物生成使用独立随机流，不改变同一种子下原有的升学、工作、家庭、健康和寿命结果；
- 当前上限为一生 8 位反复出现的人，避免人物列表失去辨识度。

## 玩家可见信息

游戏主界面的“这一生认识的人”显示当前仍在人物网络中的重要人物、关系身份、认识年数和最近联系年份。当年新相识或重新联系也会进入年度事实，让人物关系与玩家刚做的行动相互对应。

成年阶段还会把伴侣、仍在世的父母和孩子放入同一人物视图。父母按实际出生年逐岁变老，照护工时进入年度事实；孩子从出生开始记录婴幼儿、学龄前、小学年龄、初高中年龄、青年过渡和成年生活阶段。玩家每年安排的家庭照护时间会改变与孩子的共同相处时数和累计支持年数，但当前版本不会伪造孩子具体就读的学校或成年职业。

## 验证

```powershell
npm run social:check
npm run engine:check
```

前者检查虚构标识、亲近度边界、姓名池、全阶段角色以及所引用年度行动；后者实际走完一生，断言人物跨阶段保留、全部明确为虚构，并能由展示层读取。
