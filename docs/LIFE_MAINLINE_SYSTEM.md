# 动态人生主线系统

## 主题

《1978—一生》的主线不是“考大学、发财、买房、结婚”中的任何一条固定路线，也不是把五项属性加满。主线是：

> 在时代、家庭和现实条件中，通过具体生活逐渐成为一个具体的人。

玩家出生时没有职业标签或预设理想。季度行为、兴趣投入、成长经历、教育、工作、人物关系、住房、健康和真实账本共同让方向显现；方向可以持续、改变或被放下。

## 七个人生章节

| 年龄 | 章节 | 核心问题 |
| --- | --- | --- |
| 0～5岁 | 认识世界 | 我在怎样的生活里长大，又会反复靠近什么？ |
| 6～11岁 | 家庭与学校 | 在功课、家庭、朋友和玩耍之间，我正在长成怎样的人？ |
| 12～17岁 | 开始选择方向 | 成年生活正在靠近，我准备把时间和本事带到哪里？ |
| 18～24岁 | 进入社会 | 我怎样获得自己的生活入口，又愿意为哪条路付出时间？ |
| 25～39岁 | 建立自己的生活 | 工作、住处、关系和愿望之间，我要建立怎样的生活？ |
| 40～59岁 | 守住与改变 | 责任越来越多，我要守住什么，又还有什么可以重新选择？ |
| 60岁以后 | 后来的日子 | 离开全职工作以后，我怎样生活，又会把什么留在关系和记忆里？ |

章节按真实年龄推进，不替代童年、小学、青少年、升学初职和成年模拟阶段。模拟阶段负责现实结算，人生章节负责持续的玩家目标与回顾。

## 每个阶段的三个课题

每一章同时生成三条课题：

1. **眼下要维持**：健康、日常时间、教育或工作状态、实际住处和账本等生存事实。
2. **正在积累**：认知能力、学习或工作经验、成长线、关系网络和面对变化的余地。
3. **想要靠近**：从反复行为中形成的个人方向，不由出生界面直接选择。

进度百分比只是把多个具体指标组合成游戏反馈。展开后必须看到每个指标的当前值与目标值；它不冒充社会阶层、心理测验或人生成功评分。阶段目标允许多种完成方式，例如继续教育、受训、正式就业和家庭经济活动都可以形成真实的社会生活入口。

## 六种可变化的人生方向

- 理解与求知；
- 动手与实践；
- 表达与创造；
- 关系与共同生活；
- 身体与生活节律；
- 工作与生活保障。

方向分数读取相关兴趣当前分、累计投入小时以及跨季度行动次数。它描述“什么在这段人生中反复出现”，不等于性格标签或职业锁定。持续进行求知行动会提高理解与求知方向；持续进行社交和家庭行动会提高关系与共同生活方向。相同种子下只改变这些行为，会形成不同方向结果。

## 行动、结算和主线的连接

行动卡在属性、兴趣和成长预览之前显示：

- 推进哪条眼下课题；
- 推进哪条发展课题；
- 是否靠近当前最有连续性的人生方向；
- 或是在探索另一种可能方向。

这只是可能影响。季度结算仍读取实际小时、健康打断、人物回应和随机事件。年度结算展示三条课题当年的实际进度；行动不会为了完成主线而绕过现实条件。

6～17岁之间，动态方向会进入五次具体的主线兑现事件。它们不是额外加分题，而是让早期行为转成具体的人、时间冲突、现实任务和成年入口。完整规则见[0～18岁主线兑现系统](YOUTH_MAINLINE_PAYOFF_SYSTEM.md)。

## 阶段回顾与结局

章节结束时保存可复算的回顾：经历过多少季度、安排过多少具体行动、哪条方向出现最多、可见属性中最明显的变化、实际行动支出和重要人生转折。章节回顾进入成长页与自然年表。

人生结束后，主线复盘回答：

- 哪条方向在一生中反复出现；
- 哪些生活方向直到晚年仍被守住；
- 哪些投入很多但后来逐渐放下；
- 走过了多少人生章节；
- 哪些关键道路当时没有选择。

结局继续保留原有教育、工作、关系、住房和资产事实，但不再只用人物原型概括整个人生，也不计算唯一总分。

## 调试与验收

调试报告包含当前章节、当前方向、三条课题、具体指标、已完成章节及结局主线。建议使用1、7、13、18、30、45、60和75岁检查全部章节。

```powershell
npm run mainline:check
npm run browser:check
npm run release:check
```

`mainline:check`验证七个人生章节、三类课题、事实指标、行动主线提示、受行为影响的动态方向、章节因果回顾、年表节点和人生结局复盘。
