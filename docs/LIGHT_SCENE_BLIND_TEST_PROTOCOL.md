# 《1978—一生》G1 小范围盲测协议

版本：1.0　日期：2026-08-23　状态：待执行，尚未完成实际盲测

本协议供 5–8 人探索性盲测使用。范围严格限定为“1984 年、6 岁、放学后院落”G1：院门 → 院中 → 家中，目标单人体验 10–12 分钟。它不是市场规模研究，也不替代自动合同或浏览器验收。

## 1. 研究问题与样本

本轮只回答以下问题：

1. 新玩家能否在无教学、无提示下发现第一个可行动对象；
2. 玩家是否理解“对象 → 短动词 → 主角动作 → 物件/人物反馈”的闭环；
3. 弹珠事件是否被理解为现场发生的选择，而不是弹出的文字题；
4. 玩家是否愿意继续第二次行动或重玩另一条路线；
5. 玩家能否用一句话说出自己做了什么及其可见后果。

建议招募 5–8 人，彼此单独测试：

- 4–5 名普通手机游戏玩家；
- 1–2 名叙事/模拟类玩家；
- 至少 1 名不常玩游戏的人；
- 排除开发者、参与 G1 内容编写者、已读本项目规格者和会主动照顾评价的熟人。

记录受试者编号，不记录真实姓名进入结果表。样本少于 5 人时只能作为预警信号，不作比例或市场推断。

## 3. 主持人口径：不教学玩法

开始前只说：

> “这是一个约 10–12 分钟的浏览器体验。请把自己当作第一次玩的人，按你自然想做的方式操作。过程中我会尽量不帮忙；如果卡住，可以直接说‘我卡住了’，我会记录但不会告诉你该点哪里。体验结束后我会请你复述刚才发生的事。”

允许的中性回应：

- “你可以继续按自己的理解试试。”
- “我先记一下，不提示。”
- “如果你决定不继续，也可以随时结束。”

禁止的回应或暗示：

- 指向具体人物、物件、按钮、舞台或下一步；
- 解释“时间格/事件/长期影响”的规则；
- 说“这里应该点伙伴”“你可以试试帮忙找”；
- 帮忙操作鼠标/手机，代替受试者完成动作；
- 用“很好/正确/你理解了”评价选择。

若受试者连续 30 秒无法继续，只记录“卡住”，然后问：“你想再试一次，还是结束体验？”不得补课。若发生阻断性错误，可按原操作复现一次并结束该轮，标记为技术阻断。

## 4. 单人 10–12 分钟流程

主持人使用秒表和屏幕录制时间轴；时间从受试者第一次看到可操作场景开始。

| 阶段 | 目标 | 主持人动作 | 不得给出的提示 |
| --- | --- | --- | --- |
| 0:00–0:45 | 进入与第一行动发现 | 记录首次聚焦、首次点击、首次有效动作；保持安静 | 不说“点这里”或“先找伙伴” |
| 0:45–3:00 | 首个行动闭环 | 记录对象、短动词、动作、反馈、时间变化、误触/重复点 | 不解释按钮含义或收益 |
| 3:00–7:30 | 自然继续与弹珠事件 | 记录是否主动找第二对象、事件选择、事件前后复述线索 | 不提醒“有事件”或推荐选项 |
| 7:30–10:30 | 走到家中余波 | 记录是否继续到家中、是否提前停止/退出、能否观察家庭回应 | 不催促完成或代选 |
| 10:30–12:00 | 收束 | 若仍在流程中，记录自然终点；不为凑时长强行引导 | 不说“最后请点某项” |

若玩家提前完成，立即进入收束；若 12 分钟仍未完成，不加教学，记录停留节点和状态后结束。体验后追加最多 5 分钟访谈：先让玩家复述，再问开放题，不把答案暗示给他。

## 5. 非诱导任务口令

只在需要统一任务时使用以下原话，按顺序逐条给出，不说明成功条件：

1. “请从现在开始，按你自然的想法体验这一段。”
2. “当你觉得这段体验告一段落时，请告诉我。”
3. “如果你还有时间和兴趣，可以继续做下一件你想做的事；也可以停下。”
4. “请用一句话说说：你刚才做了什么，发生了什么。”
5. “如果重来一次，你会想改变什么吗？为什么？”

不要要求受试者必须点完四项行动、必须选择某个弹珠选项或必须走到家中；这些是观察对象，不是任务答案。

## 6. 观察与指标定义

每位受试者使用[记录表](LIGHT_SCENE_BLIND_TEST_FORM.md)，时间和判断采用以下定义：

- **首次行动耗时**：从首次看到可操作场景到第一次“有效动作完成”的秒数。有效动作完成 = 玩家自主选择一个对象和动词，且出现至少一项主角动作、物件变化或 NPC 回应；仅聚焦、打开列表、误触不算。无提示完成目标：中位数 ≤45 秒。
- **首次有效动作完成率**：在无主持人提示下完成首个有效动作的人数 ÷ 有效受试者人数。目标至少 6/8；5 人时按至少 4/5 观察。
- **事件理解率**：弹珠事件后，受试者能在不看主持人解释时说出“弹珠/人物反应/自己选择或处理方式”中至少两项，并能指出一项可见后果。只说“弹窗让我选”不算。目标至少 5/8；5 人时至少 4/5。
- **第二次行动意愿**：首次行动及事件后，玩家是否主动点击/尝试另一对象或明确说想继续/重玩。询问前不算；“愿意”但未采取行动单列为口头意愿。目标至少 6/8；5 人时至少 4/5。
- **退出点**：记录 `gate` 院门、`yard-before-action`、`yard-after-first-action`、`event`、`home`、`after-ending` 或 `technical-block`，并写最后一个可见状态和主动/被动原因。
- **一句话复述**：原话记录；另标记是否同时包含“我做了什么 + 谁/什么发生变化”。不替玩家润色，不以主持人理解代替原话。

同时记录：重复点击、首次提问、卡住超过 10 秒、动作条未发现、反馈未注意、页面错误、横向溢出、键盘/减少动态阻断。录屏观察不能替代玩家原话。

## 7. 汇总阈值与问题分级

5–8 人探索性门槛：

| 指标 | 通过观察值 |
| --- | ---: |
| 首次行动耗时 | 中位数 ≤45 秒 |
| 首次有效动作完成率 | 6/8；5 人时 4/5 |
| 事件理解率 | 5/8；5 人时 4/5 |
| 第二次行动意愿 | 6/8；5 人时 4/5 |
| 能说出一个可见后果 | 至少 5/8；5 人时 4/5 |
| 主动退出/技术阻断 | 不得有未记录、未分级的阻断问题 |

这些阈值只决定回到 G1/G2 修订、继续小范围验证或形成下一闸门建议，不代表产品市场成功。

问题严重级别：

- **S0 阻断**：崩溃、白屏、丢失状态、无法操作或隐私事故；立即停止该轮，不能以数据通过掩盖。
- **S1 严重**：多数人无法发现首个对象/完成行动，事件无法理解，或主持人必须教学；暂停扩张，修复后重测。
- **S2 重要**：一人以上明显卡住、反馈不被注意、重复点击/误触导致错误理解或关键设备布局阻断；列入下一修订批次并复测受影响路径。
- **S3 轻微**：文案、焦点、节奏或视觉层级问题，不阻断主流程；记录优先级，可排入后续。

任何 S0/S1 都使本轮“未通过”，不因样本少而降级。汇总必须列出证据受试者编号、时间轴、截图/录屏时间点和复现条件。

## 8. 录屏、截图与隐私同意

只在开始前取得明确同意，且把“参加测试”和“录制”分开：

- [ ] 我同意参加本次产品体验测试；
- [ ] 我同意记录屏幕、点击/停顿和主持人观察；
- [ ] 我同意录制声音/访谈（可不同意，不影响参加）；
- [ ] 我知道可以随时停止，不影响任何权益；
- [ ] 我知道结果以受试者编号汇总，不公开姓名、头像、聊天内容或其他可识别信息；
- [ ] 我同意将录屏/截图保存至：________，保存至：________，之后由：________删除/归档。

不采集身份证件、通讯录、密码、支付信息或与 G1 无关的个人内容。录屏前关闭通知、聊天窗口和其他敏感页面；截图只保留游戏画面及必要设备信息。拒绝录制时仍可使用不录屏观察表，不能把“未录制”填成“无问题”。
