# 社会模拟模型

## 1. 已确认的产品原则

- 主模式从出生开始，首批人物出生于 1978～1982 年。
- 玩家经历的是一名具体人物的一生，不是历史知识问答。
- 社会变化通过家庭、学校、工作、住房和关系产生影响，不以背景文案代替模拟。
- 健康、财富、心情、能力、人际五项属性保留，承担清晰的游戏反馈。
- 社会状态不使用“教育资源普通”“负担中等”“收入稳定性偏低”等人工标签。
- 所有社会判断必须来自可追溯的具体事实和时间变化。
- 历史数据描述群体分布和变化，不决定某个具体人物的必然命运。

## 2. 三层结构

### 2.1 事实层：唯一可信状态

系统保存人物、家庭和环境实际发生的事情。

人物事实：

- 出生年月、性别、出生地、常住地、户籍状态。
- 父母、兄弟姐妹、伴侣、子女和其他重要关系。
- 就学记录、考试结果、证书、技能和工作经验。
- 每一段工作的行业、职业、单位性质、合同、工龄、工时和实际收入。
- 身体状况、疾病、治疗、照护需求和医疗支出。
- 每段关系中的联系频率、共同经历、帮助、冲突和承诺。

家庭事实：

- 每位成员的收入与劳动时间。
- 现金、存款、生产资料、住房和其他资产。
- 房租、贷款、日常消费、教育、医疗和照护支出。
- 共同居住成员、赡养对象和需要照顾的人。

环境事实：

- 当前年份、地区和城乡位置。
- 当年各行业就业、工资和失业分布。
- 当地生活成本、教育供给、住房制度和社会保障制度。
- 已发生的政策节点与经济冲击。

### 2.2 计算层：从事实派生状态

派生指标不作为人物出生时的固定标签，也不直接写进剧情。

收入波动由最近若干年的就业月份、各月收入、合同状态、行业环境和工龄计算。

家庭经济压力由必要支出、债务偿还、教育医疗支出、照护成本、可支配收入和可用时间计算。

教育机会由当地学校供给、人物成绩、家庭实际可支付费用、照护者可投入时间、招生制度和迁移条件共同生成。

职业机会由年龄、教育、技能、经验、地区、行业、单位性质、关系信息和当年劳动力市场共同生成。

住房压力由居住面积、产权或租赁状态、房租或还贷、家庭人数、通勤成本和当地住房价格共同生成。

### 2.3 游戏层：玩家可以理解的反馈

五项属性是事实层的摘要，不替代事实层。

| 属性 | 主要来源 | 主要游戏用途 |
| --- | --- | --- |
| 健康 | 身体、疾病、劳动强度、休息、医疗 | 体力、患病风险、寿命和可选行动 |
| 财富 | 家庭净资产、现金流、负债和住房 | 抗风险能力、消费和投资选择 |
| 心情 | 压力、满足、休息、损失与关系体验 | 主观状态、行为倾向和结局回顾 |
| 能力 | 教育、技能、经验和持续练习 | 学习、工作和解决问题的表现 |
| 人际 | 具体关系中的信任、联系和支持 | 可获得的帮助、陪伴和关系事件 |

玩家可以看到属性增减，但每次变化都必须能追溯到一项具体事实或事件。

## 3. 年度模拟顺序

后台以一年为基本时间单位；界面只展示有意义的事件和阶段总结。

1. 年份推进，所有人物增长一岁。
2. 读取当年地区、行业、教育、住房和制度数据。
3. 更新家庭成员的就业、工时和收入。
4. 结算家庭消费、住房、债务、教育、医疗和照护支出。
5. 更新在校人物的学习、考试、升学和辍学状态。
6. 更新健康、关系和家庭结构变化。
7. 根据当前事实生成可发生的个人事件与时代事件。
8. 玩家在需要承担取舍的节点做选择。
9. 将选择写回事实层，再计算五项属性反馈。
10. 记录未选择的分支条件，供下一局发现，而不提前展示完整结果。

## 4. 概率与现实数据

现实数据只用于四种用途：

- 初始化某年、某地区人群的合理分布。
- 校准教育、就业、收入、迁移、住房和健康的转移概率。
- 确定重要制度变化从何时开始影响哪些群体。
- 检查大量模拟结果是否与历史统计的大方向一致。

不得把全国平均收入直接赋给一个人物，也不得把群体统计差异写成个人必然结果。具体人物从条件分布中抽样，并受到玩家选择与随机冲击影响。

## 5. 历史与未来的边界

- 1978～2025：使用已发生的历史统计和政策进行校准。
- 2026：使用当前已发布统计与已生效政策；数据缺失处明确标记。
- 2027 年以后：属于情景推演，必须与历史校准数据分开存放，不得称为真实历史。

首版可以完整模拟到晚年，但结局页应说明后半段包含统计情景推演。

## 6. MVP 的适当简化

第一版不模拟所有社会细节，只保证三条核心链闭环：教育、职业、住房。

医疗、婚育、养老和代际支持保留必要字段与事件接口，但在三条核心链验证后再扩展。这样既保留现实因果，也不会让第一版失去游戏节奏。

## 7. 当前实现状态

1978～1982年出生系统、0～6岁年度模拟、小学教育链，以及初中教育/青少年劳动准备分叉已经实现，详见[出生系统](BIRTH_SYSTEM.md)、[0～6岁年度模拟系统](CHILDHOOD_SYSTEM.md)、[小学教育年度模拟系统](PRIMARY_EDUCATION_SYSTEM.md)与[初中教育和青少年劳动准备系统](ADOLESCENCE_SYSTEM.md)。实现遵循事实层、计算层、游戏层分离：档案保存具体家庭、收入、教育支出、劳动、健康、出勤、学习和选择事实，五项属性引用事实派生，未校准内容保持空值或明确标为建模假设。下一步进入高中阶段教育与真实职业机会生成。
