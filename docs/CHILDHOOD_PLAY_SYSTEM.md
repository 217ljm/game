# 3～12岁完整玩法纵向切片

## 1. 目标与边界

3～12岁现在不是每年重复选择“学习、玩耍或帮家里”的空壳阶段。系统仍以家庭收入、健康不适、是否实际入学、学校形态、出勤和家庭劳动等既有事实作为现实约束，同时在季度层记录玩家本人能做的具体事情。

成长点、兴趣分数、人物信任和五项属性都是游戏反馈，不冒充标准化测验、临床评估或社会阶层标签。是否入学、学习进展和家庭现金仍由各阶段的现实结算负责。

## 2. 分龄活动池

1岁现有6种眼前反应：回应声音、反复摆弄物件、朝光亮移动、模仿发音、跟随节奏和把物件递给熟悉的人。2岁现有7种自主尝试：说出词语、搭放物件、靠近其他孩子、留下图画痕迹、寻找配对容器、承担小家务和重复动作游戏。这些不是照护者替玩家作出的选择，会分别影响语言、节奏、社交、观察、创作、家庭参与和活动休息。

3～12岁当前共7个活动池、52项详细活动：

- 3～5岁：想象游戏、听故事、涂画、收集比较、跑跳游戏、小家务、安全制作，以及由过去探索解锁的共同编故事。
- 6岁：走一遍上学路线、认名字和数量、认识可能的同学、整理日常物件、平衡准备与玩耍，以及由探索与动手经验解锁的自制学习卡。
- 7～12岁未入学：生活文字、实际算数、同伴制作、询问入学条件、有限家庭责任与自由活动。
- 小学1～2年级：朗读、数量游戏、课间游戏、绘画或唱演、具体求助、固定家务、路线观察、睡眠安排，以及由同伴经历解锁的续讲故事。
- 小学3～4年级：问题本、借阅、合作游戏、实用制作、家庭忙时分工、连续观察、稳定运动与同伴互助。
- 小学5年级以上：一周学习计划、阅读讨论、小项目、朋友承诺、家庭协商、修补改进、稳定活动、持续同伴互助与项目分享。
- 12岁阶段变化：延续兴趣、维持朋友、弄清新规则、重新协商家庭责任、保留运动睡眠和独立完成实际事务。

池的可用性读取年龄、阶段、是否实际入学、当前年级和已发生的成长经历。界面把完整候选池按类别展开，一次展示最多6项并可“换一批”；已经选中的行动跨筛选和翻页保留。被过去经历锁住的活动会显示在界面中并说明还缺什么，不会无理由消失。

## 3. 一次活动怎样结算

每个季度仍采用同页组合活动和每周时间预算。结算后，每项活动都会保存：

1. 活动地点。
2. 真实参与者或“我自己”。
3. 三步实际过程。
4. 计划小时与受健康不适、日常打断影响后的实际小时。
5. 参与人物的具体回应。
6. 本季度结果及完成程度。
7. 对兴趣、成长线、人物关系和年度属性结算的引用。

行动卡在选择前先给出潜在影响；季度结果再把实际属性整数变化、属性积累、兴趣分数、成长点和节点分别列出。成长页会显示最近一次行动留下了什么，玩家可以从结果追溯到来源，而不是只看到一份静态档案。

没有详细脚本的旧活动和时代娱乐也会生成符合类别的过程，而不是只显示属性增减。实际小时在计划值的合理区间内波动，已有症状日会降低执行比例；这只是生活执行模型，不推断具体疾病。

## 4. 六条连续成长线

系统保存兴趣与探索、同伴与朋友、家庭参与、学校适应、活动与休息、动手与独立六条成长线。

每条线在4、12、24点分别进入“开始形成”“持续发展”“形成稳定方式”，共18个成长节点。达到节点时会：

- 写入年度事实和人生记忆。
- 在季度结果卡中说明发生了什么。
- 显示下一步解锁提示。
- 让要求真实前史的后续活动变为可执行。

例如，“普通物件想象游戏”会先形成兴趣与探索；之后才可能出现“共同编完整故事”；持续观察可以发展成跨周项目，再发展为把过程讲给别人。朋友、家庭、学校、健康与动手线同样通过过去行为推进，而不是预设标签。

## 5. 随机事件与成长线

3～12岁的季度随机事件现在也会留下记忆，并按玩家的具体回应推进相关成长线。例如观察小动物会进入探索经历，邀请同伴会进入朋友经历，身体活动会进入健康节律。随机事件仍按年龄、阶段、活动类别和冷却期判断，不保证每季度发生。

调试模式的“高频事件”和“指定事件”仍可检查随机事件；它们只影响激活节点以后的调试历史。

## 6. 持续人物

需要同伴或老师的活动会生成并复用虚构人物。人物现在保存姓名和角色、性格特点、熟悉/信任/亲近/冲突记录、最多10条共同活动记忆及最近联系年份。

家庭活动引用已经存在的母亲、父亲或手足，不给家庭成员凭空更换身份。所有生成姓名与人物性格均明确标记为虚构。

## 7. 对现实结算的长期影响

成长线不会直接替代学校和家庭事实。小学学习进展仍先读取教学日、实际出勤、病假、家庭劳动、每周学习时间、能力和年度波动；在此基础上，过去形成的“学校适应”和“兴趣与探索”提供最多6分的有限游戏加成。该加成、输入点数和最终学习进展都会写入同一个学校年度事实，可在调试报告中核对。

兴趣系统继续按实际投入小时累积和衰减。儿童成长线、兴趣和人物网络会跨阶段保存，因此成年调试报告仍能查看童年形成的轨迹。

## 8. 界面与年表

游戏页新增：

- “刚刚真实发生”：展示上一已结算季度的过程、人物、实际小时、回应和结果。
- “当前年龄行动池”：提供类别筛选、“换一批”、预算合计、已选摘要与每项行动的潜在影响。
- “这次实际改变”：在季度结果中区分属性变化、属性积累、兴趣、成长线和人物关系。
- “最近一次行动留下的变化”：在成长页保留上一季度的来源与结果。
- “3～12岁成长轨迹”：展示成长点、阶段、下一节点距离和最近活动。
- “最近留下的记忆”：展开查看首次活动、成长节点与随机事件记忆。
- 人物卡：展示性格、熟悉、信任和最近共同经历。

自然年年表仍以年度汇总为主；展开季度明细后，可以看到每季度的实际参与者、结果和成长节点。
