# 人生调试台

## 入口与隔离

正式游戏仍使用：

```text
http://127.0.0.1:4173/
```

本地调试台使用：

```text
http://127.0.0.1:4173/?debug=1
```

调试面板只有查询参数 `debug=1` 存在时才显示。正式存档使用 `people-life:active:v5`，调试存档使用 `people-life:debug:v1`；调试跳转、手动选择和结局不会读写正式存档或正式结局画廊。

## 年龄和季度跳转

关键年龄快捷入口包括：

`0、1、2、3、5、6、7、9、11、12、15、16、17、18、22、30、45、60、75、结局`

也可以输入 0～120 岁，并选择：

- 本岁首个操作；
- Q1～Q4 前后最近的可操作节点；
- 年度结算。

跳转不是直接修改 `age`。调试器从出生开始，使用正常季度计划和关键事件选项确定性回放，保留家庭收入、教育、兴趣、人物、职业、关系、住房、健康和财务前史，再停在目标节点。如果目标季度在该年龄不是主动季度，例如 1 岁 Q1，状态栏会说明实际停在随后可操作的 Q3。

默认关闭“允许目标年龄前自然死亡”时，童年生存风险关闭，成年死亡只在目标年龄前被调试保护；到达目标后恢复正常死亡风险。打开该选项后，人物可能在目标年龄前结束，调试台会说明没有到达目标。

## 路线预设

预设通过正常候选的偏好评分建立前史，不直接写入学历、岗位、伴侣、孩子、现金或健康值：

- 教育/就业：自然均衡、学业与升学、技能与中职、较早参加工作；
- 成年家庭：自然发展、伴侣与孩子、单身独立生活；
- 资源/健康：普通生活压力、现金紧张倾向、健康压力倾向、健康保护倾向。

预设是测试路线倾向，不是对结果的虚假保证。具体结果仍受同一套收入、升学、岗位、家庭和时间约束影响；调试报告会显示最终实际状态。

## 关键事件导航

“直接调试关键事件”目录读取五份阶段事件配置和0～18岁主线兑现配置，当前覆盖全部 32 个关键事件：

- 主线兑现：6、9、12、15、17岁的经历兑现、时间冲突、阶段延续、现实检验与成年入口；

- 童年：照看者忙碌、接触文字、入学准备；
- 小学：入学时间、三年级忙季、毕业方向；
- 青少年：初中入学、费用安排、毕业方向、非在校方向、16 岁方向；
- 高中/中职：入学安排和毕业前方向；
- 成年：大学入学/毕业、初职、迁移、伴侣、住房、孩子、中年工作、父母照护、健康、退休和晚年时间。

选择事件后，调试器会尝试推荐路线和若干确定性种子。只有正常模拟真正走到该事件时才停止；找不到时会列出尝试次数和停止节点，不会强行伪造事件条件。

## 随机事件

随机事件有三种模式：

- 正常概率：使用正式概率和独立季度随机流；
- 高频合法事件：每个季度从当时合法候选中抽取一个，仍受冷却期限制；
- 指定下一事件：只有指定事件在当前年龄、年代、教育、就业、家庭和本季活动条件全部成立时才发生。

在已经到达某个节点后切换高频或指定模式，只从当前年份/季度起生效，不会因为确定性重放而改写此前几十年的事件历史。从出生新建调试档时选择该模式，则会按选择从第一个适龄季度开始生效。

状态检查列出全部随机事件。绿色表示当前可触发；其余会说明具体原因，例如年龄范围、人生阶段、就业状态、需要孩子、需要年长父母、本季活动类别或冷却期。

## 逐步推进与报告

到达目标后可以：

- 自动回答当前节点；
- 推进到下一季度；
- 推进到下一岁；
- 跳到下一个关键年龄；
- 继续使用游戏原本的选项手动测试。

“状态、事件条件与报告”显示当前年龄、阶段、等待类型、五项属性、教育、就业、家庭、财务、兴趣、3～12岁成长线、人物和事件数量。导出的 JSON 包含：

- 完整调试存档；
- 出生档案；
- 当前教育、职业、家庭、住房、财务、健康、兴趣、儿童成长线和人物状态；
- 最新年度及季度记录；
- 各阶段记录覆盖；
- 全部随机事件条件诊断；
- 54种季度基础活动、52项3～12岁详细活动、6条儿童成长线、18个成长节点、10个兴趣领域、18个随机事件、5个主线兑现事件和32个关键事件的内容目录数量；
- 最近一次自动回放步骤和错误堆栈。

## 推荐回归顺序

日常快速回归：

`0 → 3 → 5 → 6 → 7 → 9 → 11 → 12 → 15 → 17 → 18 → 30 → 60 → 75 → 结局`

完整内容回归应再分别测试：

1. 3岁活动与同伴、5岁解锁、6岁入学准备、7岁学籍分支、9岁年级活动、11岁高年级活动和12岁跨阶段保留；
2. 四种教育/就业路线；
3. 伴侣与孩子、单身独立两种成年路线；
4. 三种资源与健康倾向；
5. 32 个关键事件目录，其中单独检查5个0～18岁主线兑现事件；
6. 18 个指定随机事件及不可触发原因；
7. 高频随机事件模式；
8. Q1～Q4、年度结算和四种逐步推进；
9. JSON 报告导出、独立存档和手机竖屏。

## 自动验收

```powershell
npm run debug:check
npm run childhood:play:check
npm run youth-mainline:check
npm run browser:check
npm run release:check
```

`debug:check` 验证全部19个年龄节点、季度/年末跳转、前史连续、随机事件模式、路线预设、家庭预设、32个关键事件目录、结局和报告结构。`youth-mainline:check`完整走过五个主线兑现事件，检查条件锁定、解锁行动、延迟回响、持续人物和18岁因果链。`browser:check`在真实浏览器中检查事件证据、所得/代价和成长页复盘，同时确认调试存档与正式存档隔离。
