# 《1978—一生》G1 首个轻场景脚本：院中放学后

版本：1.0　日期：2026-08-23　状态：G1 叙事/关卡规格冻结稿

数据源：[data/gameplay/light_scene_yard_1984.json](../data/gameplay/light_scene_yard_1984.json)

## 1. 切片定位

本切片不是一张行动菜单，也不是完整人生的缩小版。它只表现1984年初秋，一个六岁孩子放学回到家属院后，天黑前的一段自由时间。

玩家要先看见人物、物件和现场，再点击一个对象，完成一个短动作，看到人物或物件回应，最后把这件小事带回家庭和季度记录。

本切片的成功标准不是玩家记住了多少文字，而是玩家能说出：

- 我选择了和谁相处；
- 我亲自完成了什么动作；
- 谁对我的行为作出了反应；
- 如果再来一次，我会换一种做法。

## 2. 三个舞台

### 2.1 院门：被生活接住

作用：建立放学后的时间、家门方向和院中邀请。

画面只放书包和家门两个主要对象。书包是“我刚从学校回来”的证据，家门是照护者的召回方向。玩家从院门进入院中，不需要操作角色连续走路。

短过场：放学铃声刚散。／院门吱呀一声开了。

### 2.2 院中：小小的自由时间

作用：让玩家在伙伴、石桌、弹珠和车棚之间作出第一组生活选择。

画面同时保留四个对象，但情境动作条只展示当前对象的动作。玩家可以先加入弹珠，再处理弹珠事件，也可以练字、看看自行车，然后在时间变暗前回家。

主要环境反馈：树影轻动、晾衣绳、远处车铃、天色变化、照护者的呼唤。

### 2.3 家中：小事留下余波

作用：将院中的选择带回家庭，不用长篇总结解释结果。

家中展示照护者、碗筷和作业本。玩家可执行“帮忙摆碗”，看到照护者的姿态和语气变化。季度记录再展开同伴、兴趣和家庭三类余波。

短过场：屋里传来碗筷碰响。／天色一暗，家门亮了。

## 3. 人物职责

### 3.1 主角：你

主角不是一张属性头像。每次行动都要有待机、转向、移动或姿态变化。主角的兴趣、健康、专注和关系事实由模拟核心结算，动画只表现已经发生的结果。

### 3.2 小宇：邀请者

小宇负责把玩家拉进院中生活。他会招手、等待、让出位置、寻找弹珠和发笑。玩家若没有回应，他也应保留“等过你”的轻微记忆，而不是消失。

### 3.3 阿沙：边界提供者

阿沙在车棚边修自行车。他不是一个供玩家点击的知识菜单，而是一个有自己的事情、会被打扰、也愿意解释的年长孩子。

### 3.4 照护者：时间与家庭的锚

照护者在院门或家中提醒回家、观察作业和回应摆碗。她不替玩家安排所有行为；她只在时间、家庭责任和现场需要出现时介入。

## 4. 四项主行动

所有行动都必须遵守以下顺序：

```text
对象状态 → 玩家意图 → 可见过程 → NPC/物件回应 → 当场代价 → 长期事实候选
```

### 4.1 加入弹珠

对象：伙伴。

触发：点击伙伴，选择“加入弹珠”。

演出：小宇招手；主角靠近；主角蹲下；弹珠被推到主角面前；小宇让出位置。

回应：小宇说“你来试试？”，弹珠从伙伴手边移到玩家可操作位置。

代价：消耗两格时间，鞋底沾一点沙；玩家可能错过一次练字或询问机会。

长期候选：同伴共同时间、同伴邀请记忆、身体玩耍兴趣萌芽。

### 4.2 练一会字

对象：石桌。

触发：点击石桌，选择“练一会字”。

演出：主角坐下；纸角被风吹起；笔尖完成第一行；照护者远远看一眼。

回应：照护者说“再写两行就进门”，作业本从合着变为写了两行。

代价：消耗三格时间，错过伙伴的一次招手；这不是失败，而是一次真实的机会取舍。

长期候选：学习兴趣萌芽、专注练习、照护者的学习印象。

### 4.3 看看自行车

对象：车棚。

触发：点击车棚，选择“看看自行车”。

演出：主角靠近；脚踏带动车轮；阿沙停下手里的活；主角缩回沾油的手。

回应：阿沙说“别碰链条，会夹手”，车轮发出轻响。

代价：消耗两格时间，手指沾黑油；玩家获得一次边界提醒，而不是一条说明文本。

长期候选：动手兴趣萌芽、年长同伴边界记忆、轻微弄脏经历。

### 4.4 帮忙摆碗

对象：碗筷。

触发：进入家中，点击碗筷，选择“帮忙摆碗”。

演出：主角抱起两只碗；碗筷在桌上排开；照护者肩膀松下来；主角擦手。

回应：照护者说“今天记得搭把手了”，桌面完成一小块生活秩序。

代价：消耗三格时间，减少院中玩耍时间；这件事也可能抵消照护者对晚归的担心。

长期候选：家庭帮忙记忆、可靠性萌芽、家庭日常参与。

## 5. 动态事件：弹珠滚进车棚边

触发条件：玩家已经加入弹珠，且仍在院中活动。

演出顺序：

1. 弹珠沿砖缝滚出；
2. 小宇停下来找；
3. 阿沙抬头看向车棚；
4. 玩家在“帮忙寻找”“先问清楚”“回家去”中作出回应；
5. 弹珠位置、人物站位、余下时间和后续对白发生变化。

三项回应不是三张结果卡：

| 选择 | 现场反馈 | 余波方向 |
| --- | --- | --- |
| 帮忙寻找 | 你和小宇一起趴下找，弹珠从车轮后滚出 | 同伴合作、解决问题的第一次尝试 |
| 先问清楚 | 阿沙指出安全位置，弹珠停在车棚外 | 边界意识、谨慎行动 |
| 回家去 | 小宇把弹珠捡回手心，车棚重新安静 | 同伴未完成记忆、按时回家 |

## 6. 时间与精力表现

场景共有九格放学后时间，每格约五分钟。时间不是一屏数字报表，而是同时由以下内容表现：

- HUD中的九个小时间点；
- 树影和天色变化；
- 远处车铃或收院门声；
- 照护者的召回；
- 对象状态从可行动变为即将结束。

行动消耗分为轻、稳、专注三档。数据只声明每项行动的时间格和精力描述，不在内容文件中写属性公式。精力只表达这一个生活片段当下的状态，不重置健康、体能等全人生属性。

转场不额外扣时间。玩家可以提前停止行动，结果由当前已发生的事实决定。时间用完后，照护者把玩家叫回家，系统仍保留这一天的普通余波。

## 7. 三类季度余波

### 同伴记忆

不是把关系数值加一，而是让小宇下一次见到主角时先叫名字、让位置或保留未完成的邀请。

### 兴趣萌芽

不是立即宣布职业方向，而是记录玩家更常靠近什么、愿意重复什么。写字、弹珠和车轮都只留下第一道可能性。

### 家庭印象

不是把照护者变成任务发布器，而是记录她看见了什么：是否按时回来、是否搭把手、是否愿意先问清楚。

同一玩家可以同时留下多类余波，也可以只留下普通的一天。普通不是失败，关键是让玩家感到今天的机会已经过去，并愿意在下一次重来时换一种生活。

## 8. 实施边界

G1只实现这三个舞台、四个人物、四项行动和一个弹珠事件。禁止扩展到18岁、职业、婚姻、完整校园或大地图。

运行时必须通过稳定ID读取本文件。场景实现可以使用 `anchorId`，但坐标只属于渲染层，不得写进本内容文件。模拟核心负责事实、随机与存档；SceneRuntime只播放人物、物件、焦点和过场Cue。

所有Cue都可以跳过。跳过只改变表现时长，不改变行动结果、事件选择和季度余波。

## 9. G1验收

- 首次完整体验控制在10～12分钟；
- 玩家有8～14次有意义输入；
- 首次行动在60秒内完成；
- 至少看见一次对象状态变化；
- 至少看见一次NPC反应和一次物件反应；
- 至少消耗一次时间格并看到天色或声音变化；
- 至少触发一次弹珠事件；
- 至少留下同伴、兴趣、家庭三类余波中的一类；
- 主舞台没有长文滚动，没有一次展开全部行动；
- 关闭动画后仍可通过原生或等价对象入口完成流程。
