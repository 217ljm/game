# 职业、教育、住房核心链

## 1. 教育链

小学与初中阶段已经按本节规则实现，覆盖入学、五/六年制小学、三年制初中、教育现金支出、出勤、家庭劳动、复读、毕业和普通/职业高中阶段分流；具体边界见[小学教育年度模拟系统](PRIMARY_EDUCATION_SYSTEM.md)与[初中教育和青少年劳动准备系统](ADOLESCENCE_SYSTEM.md)。高中阶段及更高教育仍待接续。

### 保存的具体事实

- 所在年份、地区、城乡位置和学校。
- 入学、在读、毕业、转学、复读或离校状态。
- 每年学习时间、劳动时间、照护时间和缺课情况。
- 实际教育支出、家庭可支付金额和奖助学金。
- 各科表现、考试结果、学历、证书与技能。
- 父母实际投入的时间和发生过的支持行为。

### 生成机会的方式

系统先依据年份和地区生成可接触的学校与升学通道，再结合成绩、费用、家庭时间、招生规则和迁移条件生成玩家真正能看到的选项。

玩家不会看到“教育资源：普通”，而会看到具体情境：学校距离、班级规模、是否有高中、学费杂费、家庭能否支付、是否需要帮家里劳动。

### 关键时间节点

- 1986 年《义务教育法》提供制度节点。
- 1999 年高校招生规模明显扩大。
- 2006 年修订后的义务教育法明确不收学费、杂费，并逐步建立经费保障。
- 2008 年秋季起，全国城市义务教育阶段学生学杂费全部免除。

## 2. 职业链

### 工作实体字段

- 行业、职业、单位性质和地区。
- 入职年月、离职年月、工龄和职位。
- 固定工资、计件或按日收入、奖金和经营收入。
- 实际工作月份、工时、停工天数和欠薪记录。
- 合同期限、社会保险、住房公积金和其他单位福利。
- 通勤时间、职业伤害和技能积累。

### 年度结算

每年根据行业和地区的就业分布生成工作机会；已经就业的人根据单位性质、行业环境、合同、工龄和个人表现计算续聘、涨薪、转岗、停工或失业。

“收入稳定性”不存储为字段。界面需要总结时，系统读取最近 36 个月的收入和就业记录生成描述。

### 关键时间节点

- 1978 年城镇就业几乎集中在国有和集体单位，个体等非公就业占比极低。
- 1992 年后就业制度与市场化进程进一步变化。
- 1998～2002 年国有企业集中下岗对部分城镇家庭形成显著冲击。
- 2001 年加入世界贸易组织后，制造、外贸与相关服务业机会发生变化。
- 2008 年劳动合同法实施，合同与劳动保障成为新的规则条件。
- 2014 年城镇就业比重首次超过乡村，服务业成为吸纳就业的重要渠道。

## 3. 住房链

### 住房实体字段

- 地区、地址类型和住房来源。
- 单位公房、房管房、农村自建房、租赁房、自有商品房等占有形式。
- 建筑面积、共同居住人数和基本设施。
- 房租、购房价格、首付、贷款余额、利率和月供。
- 单位分配资格、住房公积金、拆迁或搬迁记录。
- 到学校和工作的通勤时间。

### 年度结算

住房不直接等于财富。系统分别记录使用价值、现金流压力和资产价值：住在单位公房可能成本低但产权不属于家庭；拥有住房可能增加资产，也可能带来长期债务。

### 关键时间节点

- 改革开放初期，城镇家庭主要租住单位或房管部门住房。
- 1988 年起城镇住房制度改革分期推进。
- 1998 年住房改革提出停止住房实物分配，逐步实行货币化。
- 1999 年《住房公积金管理条例》形成新的长期住房储金制度条件。

## 4. 三条链如何互相影响

教育提高某些职业机会，但会消耗家庭现金与时间；职业决定收入、地区和保障，进而影响住房；住房位置和债务又会反过来影响学校选择、通勤、健康与换工作的能力。

因此事件不能只修改单个数值。例如“去外地读大学”应同时创建教育记录、迁移记录、支出、家庭关系变化和未来职业候选，而不是只写“能力 +10、财富 -8”。
